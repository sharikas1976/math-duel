# Math Duel

A two-player math race for the interactive wall projector (Android).

- Question in the middle (e.g. `2 + 5`), two answer squares for each player
- First correct hit scores 1 point; then the next question appears
- First to **10** wins, or the higher score when the **3-minute** timer ends
- Wrong hit = that player is paused for about 1 second (stops random hitting)
- Answer squares are kept away from the screen edges

Game settings are at the top of the script in `app/src/main/assets/index.html`.

## Getting the APK
Every push to `main` builds the app on GitHub automatically.
Open the repository → **Releases** → newest "Math Duel build" → download `MathDuel.apk`.
Copy it to a USB stick, plug it into the projector, and open it with the file manager to install.
